## 什么是 CSS

CSS（Cascading Style Sheets）用于控制网页的样式和布局。

## 基本语法

```css
选择器 {
    属性: 值;
}
```

## 引入方式

```html
<!-- 外部样式表 -->
<link rel="stylesheet" href="styles.css">

<!-- 内部样式 -->
<style>
    body { color: black; }
</style>

<!-- 行内样式 -->
<p style="color: red;">红色文字</p>
```

## 常用属性

- `color`：文字颜色
- `background-color`：背景颜色
- `font-size`：字体大小
- `margin`：外边距
- `padding`：内边距
