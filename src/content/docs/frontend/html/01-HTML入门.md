## 什么是 HTML

HTML（HyperText Markup Language）是用于创建网页的标准标记语言。

## 基本结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>页面标题</title>
</head>
<body>
    <h1>标题</h1>
    <p>段落</p>
</body>
</html>
```

## 常用标签

- `<h1>` - `<h6>`：标题
- `<p>`：段落
- `<a>`：链接
- `<img>`：图片
- `<div>`：块级容器
- `<span>`：行内容器
