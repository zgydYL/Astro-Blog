os 标准库是 Python 与操作系统交互的核心标准库，能实现文件/目录管理、环境变量操作、进程调用等功能，是自动化脚本、跨平台开发的必备工具。
:::caution
os 库跨平台（Windows/macOS/Linux），但部分函数存在系统差异，代码中会重点说明。
:::

## 路径操作 - os.path模块
`os.path`模块，专门用于处理文件路径，解决不同系统路径分隔符（Windows用`\`，macOS/Linux用`/`）的兼容问题
### 常用api
- `os.path.abspath(path)`：获取当前工作目录，再将相对路径转为绝对路径，常用于定位项目内的文件
- `os.path.join(path)`：**最常用函数**，避免手动拼接路径导致的跨平台错误
- `os.path.dirname(path)`：获取 path 中的目录部分
- `os.path.basename(path)`：获取 path 中的文件名部分
- `os.path.exists(path)`：先判断路径是否存在再操作，防止“文件不存在”报错
- `os.path.isfile(path)`：判断该路径是否为文件
- `os.path.isdir(path)`：判断该路径是否为目录
- `os.path.getsize(file_path)`：获取指定文件的字节大小
### 代码示例
```python title="代码示例"
import os

# 获取当前工作目录
print(os.getcwd())  # E:\PythonWorkSpace\02_PythonStdlib\01-系统与文件相关

# 1.获取绝对路径
abspath1 = os.path.abspath('test.txt')
print(abspath1)  # E:\PythonWorkSpace\02_PythonStdlib\01-系统与文件相关\test.txt
abspath2 = os.path.abspath('../test.txt')
print(abspath2)  # E:\PythonWorkSpace\02_PythonStdlib\test.txt

# 2.路径拼接（自动适配系统分隔符）
dir_path = '/home/user'
file_path = 'data.cvs'
full_path = os.path.join(dir_path, file_path)
print(full_path)  # /home/user\data.cvs（因为当前系统为Windows，因此是'\'）

# 3.拆分目录路径与文件名
dirname = os.path.dirname('E:\\PythonWorkSpace\\02_PythonStdlib\\test.txt')
print(dirname)  # E:\PythonWorkSpace\02_PythonStdlib
basename = os.path.basename('E:\\PythonWorkSpace\\02_PythonStdlib\\test.txt')
print(basename)  # test.txt

# 4.判断路径是否存在，是文件还是目录
path = 'E:\\PythonWorkSpace\\02_PythonStdlib\\test.txt'
print(f'路径是否存在：{os.path.exists(path)}')  # True
print(f'该路径是否为文件：{os.path.isfile(path)}')  # True
print(f'该路径是否为目录：{os.path.isdir(path)}')  # False

# 5.获取文件大小（字节）
path = "E:\\PythonWorkSpace\\02_PythonStdlib\\test.txt"
if os.path.exists(path):
    if os.path.isfile(path):
        size = os.path.getsize(path)
        print(f'文件大小：{size}字节')
```

## 文件与目录管理
通过`os`库创建、删除、遍历文件和目录，能够实现自动化文件整理
### 常用api
- `os.mkdir(dir_name)`：创建目录，目录已存在则报错，父目录必须存在
- `os.makedirs(dir_name,exist_ok=True)`：创建多级目录，设置 exist_not=True 可以避免目录已存在的报错
- `os.remove(file_path)`：删除文件，文件不存在则报错
- `os.rmdir(dir_path)`：删除空目录，目录非空会报错
- `os.removedirs(dir_path)`：递归删除空目录，会包含子目录和父目录，目录非空会报错
- `os.listdir(dir_name)`：返回 dir_name 下的所有目录、文件名组成的列表
- `os.walk(dir_name)`：递归遍历 dir_name 下的所有子目录，返回当前目录路径、子目录列表、文件列表
- `os.path.splitext(file_path)`：将返回元组，获取指定 file_path 的文件名、文件扩展名
