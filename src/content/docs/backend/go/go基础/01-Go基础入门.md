## Go 基础

### 第一个 Go 程序

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

### 变量和类型

```go
// 变量声明
var name string = "张三"
age := 25

// 常量
const pi = 3.14

// 数组和切片
numbers := [3]int{1, 2, 3}
fruits := []string{"苹果", "香蕉", "橙子"}

// 映射
person := map[string]interface{}{
    "name": "张三",
    "age":  25,
}
```

### 流程控制

```go
// if-else
if age >= 18 {
    fmt.Println("成年人")
} else {
    fmt.Println("未成年人")
}

// for 循环
for i := 0; i < 10; i++ {
    fmt.Println(i)
}
```

### 函数

```go
func add(a, b int) int {
    return a + b
}

// 多返回值
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("除数不能为零")
    }
    return a / b, nil
}
```
